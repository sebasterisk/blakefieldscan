reference

images array of strings, each entry is a URL that points to an image. up to 4 images work

text array of strings, each entry is text that is shown on the lower-third scrolling ticker

schedule string, which must be one of the following four-letter codes: NORM, WEDS, MASS, FORU, LATE, EARL, ANCH, AUTO.

  • if AUTO, will use schedule-infer against the calendar entries to automatically select the best schedule
  • otherwise, the selected schedule code will be used.

schedule-infer an object. each KEY is a schedule code (NORM, WEDS, etc.) and each VALUE is an array of strings that, when found in a calendar entry, uses the corresponding schedule described, in descending priority, defaulting to NORM when no others fit.
